
🚀 Introducing SewaGuru — Sri Lanka’s home-service marketplace

A web app that connects Sri Lankan households with verified home-service providers (plumbing, electrical, appliance repairs, etc.)


✨ Highlights

🔍 Verified providers with document checks + ⭐ reviews/complaints, managed via role-based dashboards. 

💬 Real-time chat after a booking (WebSockets) to coordinate details quickly. 

💳 Payments via Stripe, with a cash-on-service option for flexibility. 

🔐 Secure auth with JWT + bcrypt. 

✉️ Notifications: automated email/SMS for booking confirmations.


🛠️ How it’s built

React + Tailwind (frontend), Node/Express (API), MongoDB Atlas (data), and Supabase (secure document uploads). Tested with Postman and VS Code debugger. 

 
🎯 Impact

Built to expand access beyond major cities and improve trust in the home-service economy across Sri Lanka. 


☁️ Deployment & Live

🕸️ Frontend: Vercel

⚙️ Backend: Render.com
